# Release Notes

Здесь хранятся тексты для публикации в App Store и Google Play.

## Структура

```
releases/
  v1.0.0/
    ru.txt        — русский текст (App Store "Что нового" / Google Play)
    en.txt        — английский текст
  v1.1.0/
    ru.txt
    en.txt
  README.md       — этот файл
```

## Лимиты символов

| Платформа    | Поле           | Лимит    |
|---|---|---|
| App Store    | "Что нового"   | 4 000    |
| Google Play  | Release notes  | 500      |

Пиши в `ru.txt` / `en.txt` полную версию (App Store).
Для Google Play используй сокращённый вариант из первых ~480 символов
или делай отдельный файл `ru_short.txt`.

## Версионирование

Формат в `pubspec.yaml`: `MAJOR.MINOR.PATCH+BUILD`

```
version: 1.2.3+47
         │ │ │ └─ BUILD — монотонно растёт при каждой сборке (никогда не сбрасывается)
         │ │ └─── PATCH — баг-фикс, правки текста, мелкие улучшения
         │ └───── MINOR — новая фича, видимая пользователю
         └─────── MAJOR — редизайн или несовместимые изменения схемы БД
```

### Когда что менять

- Добавил новый экран или заметную фичу → MINOR + 1, PATCH = 0
- Пофиксил баг или поправил текст → PATCH + 1
- Полный редизайн / смена схемы БД без обратной совместимости → MAJOR + 1
- Каждая сборка в CI → BUILD + 1 (автоматически через `--build-number`)
