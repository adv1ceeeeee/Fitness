# План скриншотов для сторов

## Требования по размерам

| Магазин | Размер | Сколько |
|---|---|---|
| **App Store** 6.7" iPhone | 1290 × 2796 | 3-10 (минимум 3) |
| **App Store** 5.5" iPhone | 1242 × 2208 | 3-10 (опционально — fall back на 6.7") |
| **App Store** 12.9" iPad | 2048 × 2732 | 3-10 (если поддерживаем iPad) |
| **Google Play** Phone | 1080 × 1920 минимум | 2-8 |
| **Google Play** 7" tablet | 1200 × 1920 минимум | 0-8 (опционально) |
| **RuStore** Phone | 1080 × 1920 минимум | 2-8 |

## План — 8 скриншотов (закрывают все площадки)

Каждый кадр = 1 экран приложения + крупный заголовок-плашка сверху с
маркетинговым посылом. Плашки делаем в Figma по единому шаблону:

1. **Главный экран** → «Готовность: Пик. Время для тяжёлой тренировки 💪»
2. **Активная сессия** (запись подходов) → «Веди подходы за секунды — вес, повторы, RPE»
3. **Аналитика → Графики веса/прогресса** → «Прогресс на ладони — графики, тренды, рекорды»
4. **Программа** (день с упражнениями) → «Готовые программы или своя — под любую цель»
5. **Календарь** → «План на неделю — циклические и разовые тренировки»
6. **Тело** (силуэт + замеры) → «Замеры тела + динамика в одном месте»
7. **Профиль / Уровень XP** → «Геймификация без душноты — прогресс мотивирует»
8. **Инсайты / Рекомендации** → «AI-подбор программы под вашу цель»

## Как снимать

### iOS Simulator (iPhone 15 Pro Max)
```bash
# Запускаем нужный экран → cmd+s сохраняет в ~/Desktop
flutter run -d "iPhone 15 Pro Max"
```
Скриншоты автоматически 1290×2796 — App Store ест напрямую.

### Android Emulator (Pixel 7 Pro)
```bash
# Pixel 7 Pro = 1440 × 3120, для Google Play подходит
adb exec-out screencap -p > screenshot.png
```

### Готовые кадры из приложения

## Шаблон плашки (Figma)

- Высота плашки: 25% от высоты скриншота сверху
- Цвет фона: #F3F2EC (cream, как у нас в light theme)
- Шрифт заголовка: SF Pro Display Bold, 64pt (iOS), Roboto Bold 64pt (Android)
- Цвет текста: #0066FF (accent) или #1B1B1F (primary)
- Без логотипа в правом углу — на скриншоте уже видна верхняя панель приложения

## Где хранить готовые ассеты


Складывай в облако (Google Drive / Dropbox / Я.Диск) и ссылку положи в
`releases/store-listing/screenshots-location.local.md` (уже игнорится
по правилу `*.local.md`).
