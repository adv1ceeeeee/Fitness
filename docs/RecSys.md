# RecSys — Рекомендательная система

Документ фиксирует архитектуру, текущие наработки и план развития
рекомендательной системы Sportify.

> Обновлён: 2026-03-28

---

## Философия

Пользователь воспринимает систему как «умную» не из-за сложности алгоритма,
а из-за **специфичности и объяснения**. Рекомендация должна:

1. Называть **конкретные цифры** из данных пользователя
2. Давать **причину** («потому что…», «замечено что…»)
3. Появляться **в нужный момент** (перед тренировкой, после, в инсайтах)

Сравни:
- ❌ «Рекомендуем снизить нагрузку сегодня»
- ✅ «Вчера ты спал 5ч и стресс 8/10 — тяжёлую тренировку лучше перенести»

## Уровни развития

| Уровень | Описание | Статус |
|---------|----------|--------|
| Базовый | Авто-прогрессия весов/повторений | Частично реализован |
| Средний | Рекомендации на основе истории, усталости, дисбаланса мышц | **В работе** |
| Продвинутый | Персональный план на основе велнес + тело + тренировки | Бэклог |
| Экосистемный | Внешние данные (Apple Health, Garmin) + питание | Бэклог |

## Доступные данные

Все данные уже собираются — фундамент для эвристик готов:

| Таблица | Данные | Применение |
|---------|--------|------------|
| `sets` | weight, reps, rpe, started_at, performed_at | Прогрессия, время под нагрузкой |
| `wellness_logs` | sleep_hours, stress, energy, soreness, sleep_quality | Управление нагрузкой |
| `body_metrics` | weight_kg, body_fat_pct, обхваты | Прогресс тела |
| `personal_records` | weight_kg, reps, achieved_at | Пиковые результаты |
| `training_sessions` | duration, session_rpe, streak_at_start | Паттерны тренировок |
| `weekly_volume` (VIEW) | sets/reps/volume по группам мышц | Баланс нагрузки |

## Эвристики — Средний уровень (в работе)

### 1. Велнес → управление нагрузкой

**Триггер:** перед началом тренировки (или утром на главном экране)

| Условие | Рекомендация |
|---------|--------------|
| `sleep_hours < 6` или `stress > 7` | Предупреждение: лёгкий день или отдых |
| `energy < 4` | Убрать тяжёлые компаунды, снизить объём |
| `soreness > 3` для группы мышц | Не тренировать эту группу сегодня |

```
Пример: «Сегодня ты спал 5ч и стресс 8/10.
Рекомендуем лёгкую тренировку или активное восстановление.»
```

---

### 2. Прогрессия весов

**Триггер:** при открытии упражнения в сессии

| Условие | Рекомендация |
|---------|--------------|
| Последние 2 сессии: RPE ≤ 7 и все повторения выполнены | Увеличить вес на 2.5 кг |
| Провал повторений (< target) | Остаться на текущем весе ещё сессию |
| RPE ≥ 9 два раза подряд | Снизить вес или объём |

```
Пример: «Жим лёжа — последние 2 раза ты делал 10 повт с RPE 6-7.
Попробуй +2.5 кг сегодня.»
```

---

### 3. Дисбаланс групп мышц

**Триггер:** еженедельный инсайт / при составлении программы

```
if back.sets_week / chest.sets_week < 0.8:
  → «Ты тренируешь грудь значительно чаще спины.
     Дисбаланс может привести к проблемам с осанкой.»
```

Отслеживаемые пары:
- Грудь ↔ Спина
- Бицепс ↔ Трицепс
- Квадрицепс ↔ Бицепс бедра

---

### 4. Детекция застоя (плато)

**Триггер:** инсайт после 3+ недель без прогресса

```
if max_weight[exercise] не изменился за 3 недели AND rpe > 7:
  → «Застой на жиме лёжа уже 3 недели.
     Попробуй сменить схему повторений или добавить вариацию.»
```

---

### 5. Корреляция велнес → результаты (самое эффектное)

**Триггер:** раздел Инсайты, накапливается со временем

```
Сравни средний вес на упражнениях:
  дни когда sleep > 7ч vs sleep < 6ч

→ «Замечено: когда ты спишь меньше 6ч, результаты в жиме
   падают в среднем на 8%. (на основе 24 сессий)»
```

Нужно минимум ~20 сессий для статистической значимости.
Показывать только если разница > 5% и данных достаточно.

---

### 6. Контекстные инсайты после тренировки

**Триггер:** экран итогов сессии

```
→ «Лучшая сессия за 3 недели — средний RPE 6.8 при обычных 8.2»
→ «Ноги: +15% к объёму за этот месяц»
→ «18 тренировок подряд — личный рекорд!»
→ «Ты завершил все запланированные подходы впервые за 2 недели»
```

## План реализации

- [ ] **Велнес → нагрузка** — баннер на главном / предупреждение перед сессией
- [ ] **Прогрессия весов** — подсказка внутри сессии при открытии упражнения
- [ ] **Дисбаланс мышц** — еженедельный инсайт в разделе Аналитика
- [ ] **Застой** — инсайт в карточке упражнения в Аналитике
- [ ] **Корреляция велнес → результаты** — отдельный блок в Инсайтах (требует накопления данных)
- [ ] **Контекстные инсайты** — расширить экран итогов сессии

## Будущее (Продвинутый уровень)

- Персональный план нагрузки на неделю с учётом всех факторов
- Рекомендация упражнений на основе слабых мест
- Интеграция Apple Health / Google Fit (ЧСС, шаги, сон)
- Собственные ML-модели (когда накопится достаточно данных пользователей)
