# Changelog

All notable changes are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)
Versioning: `MAJOR.MINOR.PATCH+BUILD`

- **MAJOR** — полный редизайн или несовместимые изменения БД
- **MINOR** — новая фича, видимая пользователю
- **PATCH** — баг-фикс, правка текста, мелкие улучшения
- **BUILD** — монотонно растёт при каждой сборке (versionCode / CFBundleVersion)

## [1.0.0+1] — 2026-03-17 — MVP Launch

### Added
- **Авторизация** — вход/регистрация по никнейму + PIN-lock
- **Онбординг** — уровень, цель, пол, дата начала тренировок
- **Тренировки** — создание, редактирование, удаление, drag-reorder, свайп-скрытие/удаление
- **Каталог упражнений** — 80+ упражнений, группировка по мышечным группам, поиск с debounce
- **Активная тренировка** — подходы с весом/повторами/RPE, счётчик отдыха, прогресс-бар
  - Предзаполнение веса из последней сессии
  - Подсказка "Прошлый: X кг × Y (дд.мм)"
  - Автоопределение личного рекорда + уведомление
  - Подсказка увеличить вес (3 подряд сессии на верхней границе)
  - Drop-set режим, суперсеты
  - Haptic feedback, PopScope-диалог при выходе
- **Итог тренировки** — RPE сессии (1-10), подсчёт калорий, статистика
- **Календарь** — циклические и разовые сессии, конфликты, dot-индикаторы
- **Аналитика** — стрик, еженедельная статистика, график веса, прогресс по упражнению
- **Метрики тела** — 15 параметров + wellness чекин (сон, стресс, энергия, качество сна, боль)
- **Профиль** — настройки kg/lbs, cm/inches, тёмная тема, уведомления, дни отдыха, дилоад
- **Экспорт** — PDF/CSV тренировочных данных
- **Уведомления** — напоминания о тренировках, дни отдыха, взвешивание, inactivity reminder
- **Персональные рекорды** — таблица автообновляется триггером БД
- **Проверка версии** — non-dismissible диалог при outdated версии

### Infrastructure
- Supabase (Postgres + RLS), 35 миграций
- GitHub Actions CI: analyze + test + build AAB
- Sentry error tracking
- EventLogger — батчевая аналитика (20+ типов событий)
- ML-поля: `reps_target`, `sleep_quality`, `soreness`, `streak_at_start`, `performed_at`, `session_rpe`
- Аналитические таблицы: `personal_records`, `weekly_volume` VIEW, `push_notification_logs`, `user_goals_history`
- Offline queue для подходов при потере сети
