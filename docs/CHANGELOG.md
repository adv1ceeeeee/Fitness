# Changelog

All notable changes are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)
Versioning: `MAJOR.MINOR.PATCH+BUILD`

- **MAJOR** — полный редизайн или несовместимые изменения БД
- **MINOR** — новая фича, видимая пользователю
- **PATCH** — баг-фикс, правка текста, мелкие улучшения
- **BUILD** — монотонно растёт при каждой сборке (versionCode / CFBundleVersion)

## [1.3.5+11] — 2026-03-25

### Fixed
- **Программы: упражнения не добавлялись при использовании стандартной программы** — `_useProgram` обращался к `_exercises` до завершения загрузки (race condition); добавлен метод `_ensureExercises()`, который гарантирует загрузку каталога перед созданием программы; поиск упражнений стал трёхуровневым: точное совпадение → DB-имя содержит запрос → запрос содержит DB-имя
- **Экран упражнений программы: загрузка 3–4 секунды** — три Supabase-запроса (`getWorkout`, `getWorkoutExercises`, `getExercises`) шли последовательно; переведены на параллельный запуск; общее время загрузки сократилось до `max(t1,t2,t3)` вместо `t1+t2+t3`
- **Экран упражнений программы: пустой экран во время загрузки** — добавлен `_loading` флаг и `CircularProgressIndicator` вместо пустого контента; пользователь видит индикатор загрузки сразу после открытия экрана

## [1.3.4+10] — 2026-03-25

### Added
- **Программы: мульти-удаление** — иконка 🗑 справа от «Действующие программы» открывает режим выбора; чекбоксы появляются слева от каждой карточки, свайп и перетаскивание отключаются; квадрат «Выбрать все» выделяет/снимает выбор со всех программ; повторный тап на 🗑 показывает диалог подтверждения со скроллируемым списком выбранных программ; все удаления выполняются параллельно (`Future.wait`) — мгновенно; кнопка ✕ выходит из режима без удаления
- **Программы: цветовая маркировка карточек** — иконка синяя для стандартных бесплатных программ, жёлтая с бейджем ★ Pro для премиум-программ, фиолетовая для программ, созданных пользователем вручную

### Fixed
- **Программы: BOTTOM OVERFLOWED BY 22 PIXELS** — subtitle-текст обёрнут в `Flexible`; Pro-бейдж больше не вылезает за границы карточки
- **Программы: автопереключение на «Мои программы» после добавления стандартной** — `onProgramAdded` callback переключает вкладку и вызывает `_refreshWorkouts()` напрямую, минуя кэш
- **Программы: Pro-программа не добавлялась после оплаты** — `_showPaymentModal` вызывался сразу после `Navigator.pop`, конфликтуя с root-навигатором; перенесён в `addPostFrameCallback`

### Added (payment mock)
- **Макет оплаты Pro-программ** — при тапе на программу в превью отображается цена `$5`; кнопка «Купить за $5» открывает полноэкранный экран оплаты с выбором банка (Сбербанк / Тинькофф / ВТБ / Альфа-Банк), карточкой-заглушкой и кнопкой «Оплатить $5» со спиннером (2 сек.); реальная оплата не подключена

## [1.3.3+9] — 2026-03-25

### Fixed
- **Онбординг повторно не показывается** — флаг `onboarding_done` в SharedPreferences сохраняется после прохождения или пропуска онбординга; при следующем входе экран заполнения данных больше не появляется
- **Программы: автообновление при переключении вкладки** — список «Мои программы» обновляется автоматически при возврате на вкладку; свайп-обновление вручную больше не нужен
- **Программы: удаление через long-press** — удержание карточки открывает меню с действиями (Скрыть / В архив / Копировать / Удалить); ранее удаление было доступно только через неочевидный свайп влево
- **Программы: иконка `≡` открывает/закрывает панель действий** — тап по drag-handle мгновенно раскрывает панель со всеми кнопками; повторный тап закрывает; свайп тоже остался
- **Программы: ошибка удаления показывается пользователю** — при сбое `deleteWorkout` появляется SnackBar с текстом ошибки вместо тихого игнорирования

### Infrastructure
- **Supabase RLS** — исправлена политика `workouts_select`: убрано условие `deleted_at IS NULL` из RLS (фильтрация уже есть в Flutter-запросе); это устраняло блокировку soft-delete через UPDATE

## [1.3.2+8] — 2026-03-24

### Added
- **Черновик сета** — вес и повторения сохраняются в SharedPreferences на каждое изменение; при перезапуске приложения (включая хард-килл из трея) данные восстанавливаются автоматически

### Fixed
- **Восстановление упражнения после килла** — при повторном открытии незавершённой сессии приложение возвращается на то же упражнение, где пользователь был до принудительного закрытия
- **Уведомление об инактивности** — отменяется при старте любой тренировки, чтобы не приходить пользователю, который уже тренируется

## [1.3.1+7] — 2026-03-24

### Added
- **Прогноз до цели** — строка «До цели» в карточке «Прогресс тела» теперь показывает приблизительное время достижения цели (`~N нед.` / `~N дн.`) по линейной регрессии; появляется при наличии ≥3 замеров и адекватном тренде

### Changed
- **Навигация между вкладками** — переход на `StatefulShellRoute.indexedStack`; экраны больше не пересоздаются при смене вкладки, состояние сохраняется

### Fixed
- **Тултип графика тела** — значения округляются до 1 знака после запятой (было `83.8098…`); подпись легенды «Тренд (HP)» → «Тренд»
- **Кэш фаза 2** — `_refreshFresh` теперь всегда получает актуальные данные из сети через `AppCache.withForceRefresh`; устранена ситуация, когда просроченный кэш возвращал устаревшее значение в фазе обновления

## [1.1.0+4] — 2026-03-24

### Added
- **Аналитика — фильтр периода (1М / 3М / 6М / Всё)** на вкладках «Тренировки» и «Тело» (дефолт 3М); данные фильтруются на клиенте
- **HP-тренд (фильтр Ходрика–Прескотта)** на графиках прогресса упражнений и параметров тела — оранжевая пунктирная линия тенденции
- **Прогноз веса по HP-тренду** — карточка под графиком тела: «Прогноз через ~4 нед: X кг (±Y кг по тренду)»
- **Сравнение периодов** — строка под графиком объёма: ±N тр. и ±M кг vs предыдущий аналогичный период
- **Корреляция велнес ↔ объём** — два новых инсайта: «В недели с высоким стрессом объём на X% ниже» и «При высокой энергии объём на Y% выше»
- **Регулярность за 12 недель** — инсайт: % недель с 2+ тренировками вместо счётчика за текущий месяц
- **Тренд личных рекордов** — карточки на экране ЛР теперь раскрываются и показывают график роста ПР во времени (`personal_records` → line chart)
- **Поле «Рост»** (`height_cm`) добавлено в модель Profile, онбординг, редактирование профиля и раздел «Параметры тела»
- **Кэширование stale-while-revalidate** (`AppCache` + двухфазная загрузка):
  - `analytics_screen` и `home_screen` — мгновенный показ из кэша, тихое обновление в фоне
  - `workouts_screen`, `today_screen`, `personal_records_screen` — аналогично
  - `analytics_service`: 13 методов с TTL-кэшем 5–30 мин
  - `getWeeklyVolumeHistory`: горизонт увеличен 8 → 26 недель
  - `getCaloriesPerSession`: лимит увеличен 20 → 60 сессий

### Fixed
- Тоггл уведомлений: на macOS/Windows больше не возвращает `false` (`requestPermission` возвращает `true` на неподдерживаемых платформах)
- Скрытая программа: кнопки действий больше не просвечивали сквозь затемнённую карточку
- Перетаскивание программ: карточка сохраняет скруглённые углы во время drag (кастомный `proxyDecorator`)
- Deload-неделя: показывает конкретный диапазон дат («24–30 мар») и позволяет изменить дату через date picker
- Поиск упражнений: учитывает русскоязычные названия (`nameRu`) в обоих каталогах (программы и планировщик)
- Планировщик: упражнения сгруппированы по категориям с возможностью сворачивания (аналогично разделу «Программы»)
- Подсказка слайдера отдыха уточнена: «Дважды нажмите на слайдер для ввода вручную»

## [1.0.0+1] — 2026-03-17 — MVP Launch

### Added
- **Авторизация** — вход/регистрация по никнейму + PIN-lock
- **Онбординг** — уровень, цель, пол, дата начала тренировок
- **Тренировки** — создание, редактирование, удаление, drag-reorder, свайп-скрытие/удаление
- **Каталог упражнений** — 80+ упражнений, группировка по мышечным группам, поиск с debounce
- **Активная тренировка** — подходы с весом/повторами/RPE, счётчик отдыха, прогресс-бар
  - Предзаполнение веса из последней сессии
  - Подсказка "Прошлый: X кг × Y (дд.мм)"
  - Автоопределение личного рекорда + уведомление
  - Подсказка увеличить вес (3 подряд сессии на верхней границе)
  - Drop-set режим, суперсеты
  - Haptic feedback, PopScope-диалог при выходе
- **Итог тренировки** — RPE сессии (1-10), подсчёт калорий, статистика
- **Календарь** — циклические и разовые сессии, конфликты, dot-индикаторы
- **Аналитика** — стрик, еженедельная статистика, график веса, прогресс по упражнению
- **Метрики тела** — 15 параметров + wellness чекин (сон, стресс, энергия, качество сна, боль)
- **Профиль** — настройки kg/lbs, cm/inches, тёмная тема, уведомления, дни отдыха, дилоад
- **Экспорт** — PDF/CSV тренировочных данных
- **Уведомления** — напоминания о тренировках, дни отдыха, взвешивание, inactivity reminder
- **Персональные рекорды** — таблица автообновляется триггером БД
- **Проверка версии** — non-dismissible диалог при outdated версии

### Infrastructure
- Supabase (Postgres + RLS), 35 миграций
- GitHub Actions CI: analyze + test + build AAB
- Sentry error tracking
- EventLogger — батчевая аналитика (20+ типов событий)
- ML-поля: `reps_target`, `sleep_quality`, `soreness`, `streak_at_start`, `performed_at`, `session_rpe`
- Аналитические таблицы: `personal_records`, `weekly_volume` VIEW, `push_notification_logs`, `user_goals_history`
- Offline queue для подходов при потере сети
