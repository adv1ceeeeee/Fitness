## Безопасность

### Улучшить хеширование PIN: HMAC → PBKDF2
**Где:** `lib/services/pin_service.dart` → `_hashPin`
**Текущее состояние:** Итерированный HMAC-SHA256 (ключ = userId, 1000 раундов).
Слабость: ключ предсказуем (userId известен), нет соли.
**Что нужно:**
- Добавить пакет `pointycastle` или `cryptography`
- Генерировать случайную соль при `setupPin`, хранить рядом с хешем в FlutterSecureStorage
- Использовать PBKDF2 (100 000 итераций, SHA-256)
- Миграция существующих PIN: при следующем успешном входе пересохранить в новом формате

### HTTPS Certificate Pinning
**Где:** сетевой слой (Supabase клиент)
**Текущее состояние:** Нет пиннинга — MITM-атака возможна на устройстве с установленным CA.
**Что нужно:**
- Получить fingerprint сертификата Supabase
- Настроить `HttpClient` с кастомным `SecurityContext` или использовать пакет `ssl_pinning_plugin`
- Актуально главным образом для продакшн-сборки (не dev)
